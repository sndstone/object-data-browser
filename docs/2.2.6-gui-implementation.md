**2.2.6+1**. Engine versions remain 2.2.5 because this change does not change
engine implementations or the wire contract.

## Engine follow-up allowed by G22

The engine interface supports `deleteObjectVersions` but `startDownload` accepts
keys without version IDs. There is no capability advertising a complete pair of
version-scoped download/delete actions. Therefore the GUI deliberately does not
present a menu that could download the current version when a prior version was
requested. A separate engine task must add version-scoped downloads, advertise
support per adapter and verify behavior before those menu items are enabled.
No external issue or pull request was created.

  physical Android acceptance testing remain separate from these build checks.
