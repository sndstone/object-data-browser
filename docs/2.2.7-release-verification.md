- CI verification: Flutter and Python, Go, Rust, Java contract suites passed.
- Windows x64/ARM64 MSI metadata: version 2.2.7, expected installer architecture,

  machine was not tested during this release.
- Linux x86_64/ARM64 DEB/RPM: built inside Ubuntu 20.04. Every bundled ELF is
  checked for imported glibc versions; app/plugin dependencies must resolve.
  A headless GTK startup must remain running for 12 seconds on Ubuntu 20.04.
  Archive checks verify package version/architecture, fonts, engine manifests,
  and all declared engine payloads.
- Linux targets Mint 20+ through the Ubuntu 20.04 / glibc 2.31 baseline. This
  is compatibility evidence, not a claim of installation/live storage testing
  on every Mint version. Mint users should use the DEB for their architecture.

  signature verification and DMG checksum validation. Effective entitlements
  are empty, as required for the legacy-Keychain ad-hoc development path.
  Developer ID signing/notarization is unavailable, so the user chose to keep
  the DMG local and publish only Windows/Linux.
