# 2.2.5 implementation ledger

Scope: all 18 options in `improvement-plan.html`, including expressive,
interruptible motion that respects reduced-motion settings. Existing local iOS
and other changes are preserved. This ledger records implementation and
verification, not release publication.

## Work items

### Build 2: testing-feedback revision

Local test artifact: `dist/macos/2.2.5-dev2/Object Data Browser-arm64.dmg`
(2.2.5, build 2, Apple Silicon). DMG checksum and mounted app signature verified.
Ad-hoc development signing only; the earlier test DMG is preserved.

- The long View & actions menu is replaced by a collapsible icon-and-label tray
  for flat view, new prefix, select all loaded objects, loaded rows and List all.
- Name, Modified and Size headers sort directly; a second click reverses the
  order. Choosing a different column starts ascending.
- Inspector configuration, tools, event log and sharing are visible alongside
  the context tabs, without an overflow menu.
- Ordered transitions follow the active navigation axis: horizontal for tabs,
  vertical for the desktop rail. Old panels leave the opposite edge. Reduced
  motion remains supported, and expanded tool trays reveal vertically.
- Multi-file selections use independently sized single-file engine dispatches
  under one parent job. Only one file is scheduled at a time; its multipart
  workers remain parallel and bounded. Per-file outcomes nest in Event Log.
  Cancellation prevents queued files from starting; a sequential engine may
  finish its current file first. Unknown outcomes stop further scheduling.
- Mixed-size, zero-byte, partial failure, cancellation, manual-boundary,
  engine-affinity, parent-job/log integration and direction-reversal regressions
  cover the revised behavior. The older mockups below remain historical.

## Motion

Short 240 ms eased horizontal slide/fade transitions communicate workspace and
inspector changes. Selection actions resize smoothly; rows do not receive
expensive staggered entrance animations. Both the app preference and platform
reduced-motion/accessibility flags disable movement. HTML source/render previews
retain their source-first, selectable and non-executing behavior.

## Verification

Validated locally on macOS, 5 September 2026:

- `flutter analyze --no-pub`: no issues.
- Full `flutter test --no-pub`: **119 passed** after build-2 revisions; includes existing Keychain, preview, multipart-boundary and mobile bridge regressions, plus upload-batch and directional-motion checks.
- Four-engine `REQUIRE_ENGINE=1 ... pytest tests/contract -q`: Python 13 passed; Go 12 passed / 1 unsupported-live-control skip; Rust 11 passed / 2 unsupported-provider/control skips; Java 12 passed / 1 unsupported-Azure skip. No missing-engine skips.
- Live Python/Java fixture holds actual upload part requests open, then checks correlated pause/resume/cancel responses and multipart abort. Host fake-process regression separately proves owner affinity with a saturated queue.
- Synthetic query runs: 10,000 keys about 20–25 ms; 100,000 keys about 135–155 ms including isolate startup in the concurrent debug test process. These are informational local measurements, not release-mode frame-time or peak-memory benchmarks.
- `flutter build macos --release --no-pub`: successful. After an incremental build left the nested App.framework signature invalid, regenerated the app and ad-hoc re-signed that framework and app. `codesign --verify --deep --strict` passes. Effective app entitlements are empty (no sandbox), matching the development Keychain policy. This is a development artifact, not a distributable Developer ID release.
- iOS simulator Xcode Debug build: successful using `-skipPackagePluginValidation -skipMacroValidation CODE_SIGNING_ALLOWED=NO`. Validation bypass is scoped to the build command, not a global Xcode preference. Standard Flutter build first stopped at the existing Smithy plugin trust gate.
- Large-text 390 px phone regression and adaptive navigation tests pass; reduced-motion and unchanged-browser-subtree regressions pass.
- HTML inline scripts parse successfully. Final visual browser recheck was unavailable because no browser was connected; the new implementation summary is not claimed as visually revalidated.

## Release validation still required

Implementation does not imply public-release approval. No release, push or PR
was published. Existing local iOS and packaging edits were preserved.

- Provisioned physical iOS Keychain and local-network verification, and signed
  Developer ID/notarized macOS packaging must be completed before publication.
  Use the repository's documented packaging/signing path, not the locally
  ad-hoc-signed development artifact, for distribution.
- Loopback fixtures are not full MinIO/Azurite emulators or live-cloud coverage.
  Versioned-provider behavior, sustained concurrent transfers and real-provider
  compatibility still need opt-in disposable-storage checks.
- No measured claim of 60/120 fps or peak memory is made. Profile release-mode
  animation frame times under sustained progress/log traffic on target hardware.
  The query budget bounds keys/characters, not every byte of process RSS.
- Inspector/domain extraction is intentionally incremental; existing tools and
  metadata views remain in BrowserWorkspace behind the new contextual surface.

The HTML plan retains its original reconstructed before/after examples as design
references, not screenshots of the completed application.
