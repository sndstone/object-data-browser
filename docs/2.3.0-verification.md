# Object Data Browser 2.3.0 development verification

Build scope: local/emulator verification, as selected by the user. No user endpoint credentials, configured cloud resources or Keychain items were used by qualification scripts. The user subsequently requested publication of the source and this DMG to GitHub. Version 2.3.0 is distributed as a development prerelease; public Developer ID/notarized release qualification remains outside this build. Windows packages will be built separately on Windows.

## Delivered scope

- Bucket-aware access/ACL presets and lifecycle tiering presets, preserving custom statements/rules and advanced lifecycle fields.
- Current-content bucket copy across S3/Azure endpoints; resumable S3 history copy with delete-marker ordering and version mapping; reviewed, freshness-checked configuration copy after content completes.
- Conditional stale-metadata overwrite recovery only for proven never-versioned compatible buckets. Versioned/suspended buckets retain normal exact-version deletion retries; their alternative overwrite fallback remains deferred by request.
- Object metadata/headers/encryption/storage class, Object Lock/retention/holds, exact-version workflows, archive restore, multipart inspection and cleanup.
- Durable S3/Azure upload and range-download recovery with source/destination identity checks and explicit unknown-outcome handling.
- Azure account lifecycle presets, container protection, and HNS directory/ACL administration through the desktop reference adapter. Account management requires Entra/RBAC; HNS endpoints must be proven compatible.
- Shared Android/iOS REST data/admin operations, parallel bounded transfers, safe delete tools and continuous benchmark runtime. Mobile supports static S3/session credentials and Azure Shared Key/SAS; desktop credential chains and management-plane workflows remain explicitly gated.
- Benchmark connection reuse, bounded payload caches/streams/history, disk-backed payloads, actual retry/error accounting, selected checksum validation, and credential-free checkpoints.

## Boundaries

History copy requires an empty destination prefix including existing versions/markers and is limited to 100,000 entries per plan; narrow the prefix for larger histories. Original version IDs, ACLs and retention grants are not cloned. Configuration policy remapping is conservative and blocks unsafe/public grants instead of silently widening access.

Azurite does not model Azure management/RBAC, HNS, full blob version history or user-delegation credentials. Those paths have protocol/unit fixtures rather than live-provider certification. Local MinIO throughput is a same-machine measurement, not a cloud/network throughput guarantee; methodology and earlier comparisons are in [local S3 performance](local-s3-performance.md).

The macOS DMG is an arm64 development artifact with an ad-hoc signature and no sandbox/keychain-group entitlements. Public Developer ID signing, notarization, live-cloud qualification and physical iOS checks are outside this build.
