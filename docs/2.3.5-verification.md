# 2.3.5 verification

Version: **2.3.5+1**. Internal verification ran on an Apple Silicon macOS host on
2026-11-12. This prerelease contains the current resource, motion, S3 correctness,
adaptive-dialog and iPhone/iPad source improvements.

## Application and engine checks

- Flutter analysis: no issues. Full Flutter suite: **460 passed, 8 skipped**,
  including regressions for keyboard-height dialogs, retained drafts, preference
  propagation, workspace invalidation, partial batch deletion, unusual keys,
  version restoration, ACL/Object Lock preservation and bounded transfers.
- Python contracts: **178 passed, 42 skipped**.
- Go race-enabled native suite: passed. Selected transport, storage-failure and
  download-safety contracts: **40 passed, 1 skipped**.
- Rust native suite: **26 passed**. Selected transport, storage-failure and
  advanced-engine contracts: **54 passed, 2 skipped**.
- Java transfer/resource/review regression harness: passed. Selected transport,
  storage-failure and advanced-engine contracts: **55 passed, 1 skipped**.
- Workflow actionlint, shell syntax checks and diff whitespace checks: passed.

The engine checks above ran during implementation before the version-only bump.
The Flutter analysis and full suite were repeated for 2.3.5. Final packaged-engine
qualification is recorded below. Fixtures are offline/loopback and do not establish
live-cloud, Windows/Linux installer or production performance qualification.

## macOS development package

The release configuration targets **Apple Silicon arm64, macOS 13.0 or later**.
The native payload audit found that the bundled Objective-C interop framework
requires macOS 13. The project and CocoaPods minimums now match that dependency.
The Xcode 27 development host uses an external ARM64/macOS 13 xcconfig to avoid its
multi-architecture verification incompatibility. The Developer ID signing policy
is unchanged.

The DMG is an **ad-hoc signed, non-notarized development artifact**. It uses the
legacy-Keychain development path with no sandbox or Keychain-group entitlements.
Updating this artifact can require renewed Keychain authorization or credential
re-entry. It must not be represented as an update-safe Developer ID release.

The final DMG was mounted read-only. The app passed strict/deep signature
verification before and after packaged tests. Its bundle metadata reports
2.3.5, build 1, arm64 and minimum macOS 13.0; effective entitlements are empty.
All **264 native images** were inspected for deployment minimums at or below
macOS 13. The four engine executables report 2.3.5, all required manifest paths
exist, the packaged Python sources match the repository, and installed Python
dependencies match the checked-in version constraints.

## iPhone and iPad source verification

The universal iOS 15 target builds through the direct Xcode simulator workaround
described in [the iOS plan](IOS_PLAN.md). The final simulator bundle's signature,
privacy manifest and device-family metadata were inspected; launches on iPhone
17 Pro and iPad Pro 13-inch simulators were checked. Status-bar contrast and the
iPad Command-key shortcut hint were verified on screen.

No iOS installer is published with this release. Physical-device Keychain and
local-network permission flows, distribution signing, and background/interruption
qualification remain required before an iOS release. Foreground transfers stop
on backgrounding; durable background continuation is a separate feature.

## Scope

This release publishes a macOS DMG only. Windows x64 2.3.4 and Linux 2.3.3 packages
remain available from their respective releases. Live-provider and physical-device
checks, Windows/Linux requalification and controlled throughput/battery profiling
were not performed for this macOS development release.
