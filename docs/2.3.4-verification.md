# 2.3.4 verification

Version: **2.3.4+1**. Internal verification ran on an Apple Silicon macOS host on 2026-11-03.

## Internal CI

- Pinned actionlint and syntax checks for every `scripts/*.sh` file: passed.
- Flutter analysis: no issues. Full Flutter suite: **385 passed, 8 skipped**.
- Python contract suite: **147 passed, 42 skipped**.
- Go vet and race-enabled unit suite: passed. Contract suite: **146 passed, 43 skipped**.
- Rust unit suite: **15 passed**. Contract suite: **174 passed, 15 skipped**.
- Java Gradle build, transfer regression harness and distribution build: passed. Contract suite: **175 passed, 14 skipped**.
- Engine-specific skips reflect unsupported fixtures or provider features. These local contract runs use offline and loopback fixtures, not production cloud endpoints.

The internal checks use the same actionlint, Flutter and four-engine contract gates as repository CI, plus Go race checks, Rust unit tests and Java transfer regressions. They run on macOS; this is not cross-platform runner or Windows/Linux installer qualification. Engine code is unchanged apart from the version number.

## UI verification

Thirteen new regressions in `gui_review_fixes_test.dart` cover:

- the bucket refresh control showing its busy state before a slow listing completes;
- the inspector button and Cmd+I opening the inspector dialog at a 1050 px window;
- profile fields reporting "Draft" with an unsaved-change count, and setting fields showing "Saved" only after an awaited write, with failed writes reported;
- profile drafts surviving workspace replacement, the Discard / Keep editing / Save prompt when leaving Settings, a failed save keeping the draft, and Save clearing drafts;
- shortcut requests not remaining pending after Keep editing;
- log text composing with a 1.5× system text scale;
- an expanded API trace staying with its request after another request is prepended;
- the compact selector and ruler slider meeting Android and iOS tap-target guidelines on a phone-width iOS layout.

The eighth skipped test is the opt-in README screenshot capture (`README_SCREENSHOTS=1`) added on main after 2.3.3. The other seven were already skipped in 2.3.3.

## macOS build

The release configuration builds for **arm64** with minimum macOS **12.0**. The local Xcode 27 invocation uses an external xcconfig setting `ARCHS=arm64`, `ONLY_ACTIVE_ARCH=YES` and `MACOSX_DEPLOYMENT_TARGET=12.0`; project deployment defaults are unchanged. This avoids Xcode's multi-architecture `lipo -verify_arch` parsing failure.

The DMG is an **ad-hoc signed development artifact**, with no Developer ID identity, notarization or sandbox/Keychain-group entitlements. It must not be represented as an update-safe production macOS package. It is published as a labeled development prerelease at the user's explicit request.

The final DMG was mounted read-only. The app passed strict/deep signature verification before and after testing. Bundle metadata reports version 2.3.4, build 1, arm64 and minimum macOS 12.0. Effective entitlements are empty. All required engine-manifest entries exist, packaged Python modules match their source, and every bundled engine reports 2.3.4 and passes **7 offline transport contract tests** from the mounted image.
